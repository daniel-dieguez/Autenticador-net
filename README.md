# **Authentication Backend - .NET 8 & SQL Server**  

This project is a **user authentication system** developed with **.NET 8** and **SQL Server**. It enables user management and authentication to access protected resources in a web application.  

## **Features**  
✅ User registration with email and password.  
✅ Authentication based on credentials stored in SQL Server.  
✅ JWT token-based session management.  
✅ Role-based access control (RBAC).  
✅ Secure password storage with hashing.  
✅ Integration with a React.js frontend.  

## **Technologies Used**  
- **Backend:** .NET 8 (ASP.NET Core Web API)  
- **Database:** SQL Server  
- **Authentication:** JWT & password hashing  
- **ORM:** Entity Framework Core  
- **Testing Tools:** Postman for API testing
